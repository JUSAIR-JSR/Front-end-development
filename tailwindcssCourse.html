Setup & Installation

CDN Method (Quick Start)

Fastest way to start prototyping with Tailwind CSS

<!doctype html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
  <h1 class="text-3xl font-bold text-blue-600">Hello Tailwind!</h1>
</body>
</html>

CLI Method (Production)

Recommended for production projects with build process

npm install -D tailwindcss
npx tailwindcss init
/* input.css */
@tailwind base;
@tailwind components;
@tailwind utilities;
npx tailwindcss -i input.css -o output.css --watch

Core Concepts

Utility-First

Everything is a utility class for maximum flexibility

<div class="p-4 bg-blue-500 text-white rounded">

Responsive

Built-in responsive prefixes for all breakpoints

<div class="text-lg md:text-xl lg:text-2xl">

State Variants

Hover, focus, active states with prefix syntax

<button class="hover:bg-blue-600">

Dark Mode

Easy dark mode with class or media query

<div class="dark:bg-gray-800">

Customization

Extend colors, spacing, and more in config

colors: { brand: '#00f7ff' }

@apply Directive

Extract utilities into CSS components

.btn { @apply px-4 py-2; }

Advanced Features

Custom Configuration

Extend Tailwind with custom colors, spacing, and animations

// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        brand: '#00f7ff'
      },
      animation: {
        'spin-slow': 'spin 3s linear infinite'
      }
    }
  }
}

@apply Directive

Extract utilities into reusable CSS components

.btn-primary {
  @apply px-4 py-2 bg-blue-600 text-white rounded shadow hover:bg-blue-700 transition;
}

.card {
  @apply p-6 bg-white rounded-xl shadow-lg border;
}
