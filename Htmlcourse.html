Basic HTML Structure

The foundation of every HTML document

HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

Explanation

  • <!DOCTYPE html> - Defines the document type
  • <html> - The root element of the page
  • <head> - Contains meta information and links
  • <body> - Contains the visible page content

Semantic Tags

<header>Header area</header>
<nav>Navigation</nav>
<main>Main content</main>
<article>Blog post or content block</article>
<section>Section of a page</section>
<aside>Sidebar content</aside>
<footer>Footer area</footer>

Benefits

  • Better SEO and accessibility
  • Clearer document structure
  • Easier to maintain and style

Text Formatting Tags

<em>Emphasized text</em>
<u>Underlined text</u>
<mark>Highlighted text</mark>
