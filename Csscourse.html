CSS Implementation Methods

Different ways to add CSS to your HTML

Internal CSS 

<style>
h1 {
  color: green;
}
</style>

CSS written inside the HTML file using <style> tags

Inline CSS 

<h1 style="color: red;">
  Hello World
</h1>

CSS applied directly to HTML elements using style attribute

External CSS 

<link rel="stylesheet" 
      href="style.css">

CSS in separate files linked to HTML

CSS Animations & Transforms

Modern CSS Animations

Bring your websites to life with CSS animations

CSS Transitions

.button {
  transition: transform 0.3s ease, 
              background-color 0.3s ease;
}
.button:hover {
  transform: scale(1.2);
  background-color: #2980b9;
}

CSS Transforms

.card:hover {
  transform: rotate(10deg) scale(1.1);
}
Hover Me

Keyframe Animations

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-50px); }
}
.ball {
  animation: bounce 1s infinite ease-in-out;
}

Responsive Design with Media Queries

/* Mobile First Approach */
.container {
  padding: 1rem;
}

/* Tablet */
@media (min-width: 768px) {
  .container {
    padding: 2rem;
  }
}

/* Desktop */
@media (min-width: 1024px) {
  .container {
    padding: 3rem;
  }
}
